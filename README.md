# 灵感发生器 Inspire Generator

多维度随机碰撞 + AI 生成的创意灵感刷卡工具。每次打开一个新灵感卡片，适合写作、设计、创作等需要灵感启发的场景。

## Features

- **随机碰撞** — 从多维度词库随机组合，生成意想不到的创意方向
- **AI 增强** — 可选接入大模型 API，对碰撞结果进行深度润色与扩展
- **刷卡交互** — 类似卡片滑动，左右切换灵感，沉浸式体验
- **本地收藏** — 喜欢的灵感一键保存，随时回顾
- **浏览器内嵌** — 轻量 Chrome 扩展，随开随用

## Installation

1. 打开 Chrome 浏览器，进入 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目根目录即可

## Tech Stack

- **Manifest V3** — Chrome 扩展最新规范
- **Vanilla JS** — 纯原生 JavaScript，无框架依赖
- **CSS3** — 卡片动效与响应式布局
- **DashScope API** — 可选阿里云通义大模型接入
- **Chrome Storage API** — 本地收藏与持久化
